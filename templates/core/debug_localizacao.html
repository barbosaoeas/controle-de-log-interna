Como Interpretar os Dados
Status GPS:
  • Online - Localização atualizada nos últimos 5 minutos
  • Recente - Localização atualizada nos últimos 30 minutos
  • Desatualizada - Localização antiga (> 30 min)
  • Sem GPS - Nunca enviou localização
Checklist para Funcionamento:
  • Perfil deve ser TRANSPORTES
  • Operador deve fazer login no sistema
  • Permitir acesso à localização no navegador
  • GPS ativo no dispositivo
  • Conexão estável com internet
Controle de Distância:
  • Verde - Dentro do raio de 100 metros
  • Amarelo - Fora do raio de trabalho
  • Sistema só aceita precisão menor que 30 metros
Para Melhor Precisão:
  • Ative GPS no dispositivo
  • Use conexão estável (WiFi/4G)
  • Evite áreas cobertas
  • Aguarde 30-60 segundos
  • Mantenha página aberta
